## ✨ 主な特徴

- 🔢 **親指カスタムテンキー**: スマホ標準キーボードが画面を覆うストレスなし。電卓風テンキー＆`+1,000` `+5,000` `+10,000` のクイック加算ボタンで爆速入力。
- ⚖️ **リアルタイム折半・傾斜精算**: 登録した瞬間に「どちらからどちらへ何円送金するか」を常時1行表示。50:50のほか、60:40などの傾斜配分にも対応。
- 📱 **スマホ全画面PWA対応**: 「ホーム画面に追加」するだけで、URLバーのないネイティブアプリとして起動。Service Workerによるオフライン高速表示に対応。
- 📋 **LINE請求文面ワンタップコピー**: ボタン1つでおしゃれな絵文字付き請求文面をクリップボードにコピー。
- 🔒 **安心・安全のゼロサーバー費用**: 各自のSupabase（無料枠）に直接接続する「BYOD (Bring Your Own Database)」方式。作者のサーバーに個人データが保存されることは一切なく、プライバシーも万全です。

## 📖 ご利用ガイド（はじめのセットアップ手順）

### Step 1: アプリを開いてホーム画面に追加する (PWA化)

1. スマホのブラウザで **[PairPay (https://kaito2000.github.io/PairPay/)](https://kaito2000.github.io/PairPay/)** を開きます。
2. ホーム画面に追加します：
   - **iPhone (Safari)**: 画面下の共有ボタン（四角から上矢印） ➔ **「ホーム画面に追加」**
   - **Android (Chrome)**: 右上のメニュー（︙） ➔ **「アプリをインストール」** または **「ホーム画面に追加」**
3. ホーム画面に追加された「PairPay」アイコンをタップすると、**アドレスバーのない全画面ネイティブアプリ**として起動します。

---

### Step 2: 無料のSupabaseデータベースを準備する（約3分）

夫婦2台のスマホ間でリアルタイム同期を行うために、無料のデータベースを作成します。

1. **[supabase.com](https://supabase.com/)** にアクセスし、無料アカウントを作成して新しいプロジェクト（New Project）を作成します。
2. **テーブルの作成 (SQL実行)**:
   - Supabaseダッシュボードの左メニュー **「SQL Editor」** を開きます。
   - このリポジトリの [`supabase/schema.sql`](./supabase/schema.sql) の内容をすべてコピーして貼り付け、右下の **「RUN」** ボタンを押します。
3. **匿名認証の有効化**:
   - 左メニュー **「Authentication」>「Providers」** を開きます。
   - リスト内の **「Anonymous Sign-ins」** を見つけて **ON** にし、保存します。
4. **URLとキーの取得**:
   - 左メニュー **「Project Settings（⚙マーク）」>「API」** を開きます。
   - `Project URL` と `Project API keys` の **`anon` `public`** キーをコピーします。

---

### Step 3: アプリで接続＆世帯を作成する（代表者の方）

1. PairPayアプリの右上 **「⚙（設定）」** をタップします。
2. **「Supabase 連携設定」** に、先ほど取得した `Project URL` と `Anon Key` を貼り付けて **「接続して同期を開始」** を押します。
3. 接続に成功すると、画面上部に **「🟢 クラウド同期中」** と表示され、設定画面に **「現在の世帯招待コード（6桁の英数字）」** が発行されます。
4. この招待コードをコピーして、パートナーにLINEなどで共有してください。

---

### Step 4: パートナーの端末を繋げる

1. パートナーのスマホでもPairPayを開き、ホーム画面に追加します。
2. 同様に **「⚙（設定）」** を開き、Step 2 で取得した同じ `Project URL` と `Anon Key` を入力して接続します。
3. 設定画面の **「別の世帯に参加する」** に、共有された **「6桁の招待コード」** を入力して **「参加」** を押します。
4. 🎉 **これで完了です！** 片方が支出を記録すると、もう片方の画面がリアルタイムに自動更新されます。

## 💡 日常の使い方

### 1. 支出を記録する
- 画面下の **「＋ 支出を記録する」** をタップ。
- カスタムテンキーで金額を入力（`+1,000` などのクイック加算も便利です）。
- 「誰が払ったか（夫 / 妻）」と「カテゴリ」を選択し、必要に応じてメモを入力して **「この内容で記録する」** を押します。

### 2. 月末に精算する
- トップ画面の黒い精算カードに「👉 妻 ➔ 夫 へ 【¥XX,XXX】 送金」と常にリアルタイム表示されています。
- **「LINE文面コピー」** を押すと、そのまま送れる請求テキストがコピーされます。
- 送金が済んだら **「精算完了にする」** を押すと、当月分の支出がアーカイブされ、差額0円にリセットされます。

### 3. 設定の変更
- アプリ右上の **「⚙（設定）」** から、夫婦の呼び名（ニックネーム）や負担割合（折半 50:50 のほか、60:40 など）をいつでもスライダーで調整できます。

## 🛠 技術スタック & 開発手順

- **フロントエンド**: Vite 6, TypeScript, Tailwind CSS v4, Lucide Icons
- **バックエンド / DB**: Supabase (PostgreSQL, Row Level Security, Realtime WebSocket, Anonymous Auth)
- **ホスティング**: GitHub Pages (GitHub Actions CI/CD 自動デプロイ)
- **PWA**: Web App Manifest, Service Worker (キャッシュファースト / オフライン対応)

### ローカルでの開発

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動 (http://localhost:5173)
npm run dev

# 意地悪・計算負荷テストの実行
npx tsx scripts/stress-test.ts

# プロダクションビルド
npm run build
```
